## 7. The 199 versus 240 quarter-boundary issue
- **199 = the number of printed quarter-marker symbols (U+06DE)** in the official text. In V1 they are stored as 199 `quran_quarter_marks` records (an ordinal `mark`, not a quarter number) and `GET /quran/quarter-marks` returns exactly those records. Each is verified directly: its ayah's official text starts with the marker, and the set of markers equals the set of marked ayahs (validator, tests, persisted check). The package prints no marker at any surah start.
- **240 is not claimed.** `coverage.quarterStarts` states `expected 240, evidenced 199, unevidenced 41`; no hizb is stored; nothing was added from another source or inferred, and the expected count was not changed to 199.
- **The 41 unevidenced starts, per juz span** (juz: missing quarter starts): 1: 1, 4: 1, 6: 1, 8: 1, 9: 1, 11: 1, 14: 2, 15: 1, 16: 1, 17: 2, 18: 3, 19: 1, 20: 2, 21: 2, 24: 1, 26: 2, 27: 2, 28: 4, 29: 5, 30: 7 (sum 41; each juz span should hold 8). They cannot be inferred: the number of unmarked surah-initial ayahs in a span often exceeds the missing count (juz 30: 7 missing, 37 candidates), so the package does not say which ayahs they are. The full table is in `e2e-output.txt`, section 2. The **15:49** marker is established by the package (text and printed page 264).
- Impact: a quarter or hizb range unit cannot be served in V1; ayah, line, page and juz units can (juz with the caveat in section 8).
